# FJ-WEB-02.1 — Локализация и полировка форматирования книги

Доводка RU-локализации PDF-книги и предпросмотра: перевод системных событий
аддона, единый слой представления записи, исправления форматирования.
Основа — `main` после PR #2. Изменения одинаково работают в браузерном
предпросмотре и в скачиваемом PDF: оба рендера идут через один модуль.

## 1. Слой локализации `src/lib/localize.ts`

Единая точка представления события — `localizeMemory(memory, lang)` — теперь
используется **одновременно** в `src/components/MemoryEntry.tsx` (веб) и
`src/pdf/BookDocument.tsx` (PDF). Словари и правила перевода не дублируются.

Что переводится при выборе RU (и только при RU):

- **Метки типов событий** (точное совпадение, без учёта регистра):
  Zone/Zone Discovered → Зона/Зона открыта, Death → Смерть, Level/Level Up →
  Уровень/Новый уровень, Victory → Победа, Instance → Подземелье, Memory →
  Воспоминание, Quest Milestone → Этап заданий, Achievement → Достижение,
  Journal Entry → Запись в дневнике.
- **Автоописания аддона** (точное совпадение): «A new place became part of
  your journey.» → «Новое место стало частью твоего путешествия.»,
  «Your journey continues.» → «Путешествие продолжается.», «The battle ended
  in victory.» → «Битва завершилась победой.», «Every journey has its
  setbacks.» → «На пути каждого героя случаются поражения.», «Reached the
  level cap.» → «Достигнут максимальный уровень.»
- **Шаблоны с числом**: заголовок `Level N` → «Уровень N», описание
  `Reached level N.` → «Достигнут уровень N.»

Чего слой **не делает** (проверено тестами):

- не переводит произвольные пользовательские записи (заголовки, тексты,
  личные заметки) — они сохраняются дословно в любом языке;
- не трогает имена персонажей, NPC, названия зон и локаций (нет достоверной
  локализации — оставляем оригинал);
- частично известные шаблоны не переводит: `Level 20: Guardian of the Grove`
  остаётся как есть (перевод «наполовину» хуже оригинала);
- ничего не машинно переводит и не ходит во внешние API — только курируемый
  словарь в коде;
- **не изменяет импортированные данные**: `localizeMemory` — чистая функция
  над `JournalMemory`, исходный объект не мутируется (тест).

## 2. Форматирование

- **Двойная точка** «2026 г..» во вступлении устранена: русские даты Intl
  заканчиваются на «г.», поэтому точка предложения теперь добавляется
  один раз хелпером `endSentence()` (общий для EN/RU через
  `introLeadText()`); EN-вступление по-прежнему заканчивается точкой.
- **Игровое время** локализовано: `formatPlayed(totalPlayed, lang)` даёт
  «4 д 22 ч» / «45 мин» в русской книге и прежние «4d 22h» / «45m» в
  английской.
- **Мета-строка** записи «дата · локация» собирается в одном месте; локация
  обрезается от краевых пробелов, дата форматируется по языку, локация
  никогда не переводится.

  на английском (заведомо безопасное поведение); список расширяется правкой
  одного файла `src/lib/localize.ts`.
- Формат FJBOOK1, Lua-аддон и генерация PDF (постраничная логика, шрифты,
  warm-up) не изменялись.

# Ревью-фиксы PR #3 (Round 2)

## P1 — реальные шаблоны Straider

`src/lib/localize.ts` дополнен параметризованными системными шаблонами
(параметр — имя зоны/NPC/заклинания/подземелья — всегда сохраняется дословно,
переводится только обвязка):

| Шаблон аддона | Русский вывод |
| --- | --- |
| `Discovered {zone}` | `Открыта зона: {zone}` |
| `Fell in battle — {enemy}` | `Пал в бою — {enemy}` |
| `Reached Level {level}` | `Достигнут {level}-й уровень` |
| `Entered {instance}` | `Вход в подземелье: {instance}` |
| `{count} quests completed` | `Выполнено заданий: {count}` |
| `Final blow: {spell}.` | `Последний удар: {spell}.` |
| `Another chapter of your journey lies within.` | `Впереди новая глава твоего путешествия.` |
| `Another important questing milestone has been reached.` | `Достигнут ещё один важный этап выполнения заданий.` |

Порядковое числительное — `{n}-й уровень` для любого целого n (в мужском роде
номинатив всегда «-й»: 1-й, 3-й, 11-й, 21-й, 80-й) — покрыто тестами на
1/3/11/21/80. Смешанные скрипты проверены: «Открыта зона: Dun Morogh»,
«Последний удар: Pyroblast.», а также кириллические параметры
(«Открыта зона: Тирисфальские леса», «Последний удар: Огненный шар.»).

## P1 — защита авторского текста

- Изучены маркеры ручных записей: сам `JournalExport.lua` в workspace
  отсутствует (известно с FJ-WEB-01), но во всех имеющихся источниках
  (демо-журнал, фикстуры, договорённости ревью) ручные записи — это
  `type: "note"` и/или `source: "manual"`.
- `localizeMemory()` не применяет системный перевод к заголовкам и описаниям
  ручных записей (`isManualEntry`: `type === 'note' || source === 'manual'`).
  Метка типа «Journal Entry» остаётся системным UI-текстом и переводится.
- Личные заметки (`personalNote`) не переводятся ни у каких записей, включая
  автоматические события (тест: заметка при «Fell in battle — …» дословна).
- При неоднозначном происхождении приоритет у оригинала: перевод только по
  точному совпадению с курируемым словарём; частично известные и неизвестные
  шаблоны не трогаются (заголовок победы «Boss defeated» остаётся английским —
  это продемонстрировано в образцах намеренно).
- Импортированные данные не изменяются (чистая функция; тест на отсутствие
  мутаций).

Случай из ревью зафиксирован тестом: ручная запись с заголовком `Level 20` и
текстом `Your journey continues.` сохраняется дословно, при том что те же
строки у автоматических событий переводятся.
